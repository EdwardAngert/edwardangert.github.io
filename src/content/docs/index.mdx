## At work

I make documentation that you can find and follow.

I also consider a lot more things documentation than you might think:

- Button text and interface labels.
- Scope-of-support and MSA-type documents.
- The email that tells a new hire when to start, where to sit, and what the bathroom code is.
- Offboarding checklists, FAQs, and the masking tape and Sharpie on a cabinet shelf that says which containers go there.

Everyone is a contributor.

Drafts should be imperfect, and written down and findable is better than polished.

It might never be perfect, but we'll always iterate on it.
